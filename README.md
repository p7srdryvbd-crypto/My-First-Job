# My First Job

## Final Exam Web Development Project

**Course:** Technical English  
**Program:** Web Programming Technician  
**Language level:** A2  
**Project type:** Individual educational website

## Project idea

**My First Job** is a simulated website designed to help students and young people find their first job opportunity.

The website addresses a real user need: young people may not know where to search for entry-level jobs or how to start an application.

## Required six sections

1. **Home - My Web Project** — project name, welcome message and visual identity.
2. **About the Project** — purpose, problem and target audience.
3. **Website Structure** — menu, navigation and how users move through the website.
4. **Content and Features** — job opportunities, search, filters, buttons, application form and contact information.
5. **Development Process** — planning, design, coding and testing.
6. **Final Reflection** — problems, solutions and future improvements.

## Technologies

- HTML5

- Web browser for testing

## Features

- Responsive navigation menu
- Job search
- Job type filter
- Simulated job listings
- Apply buttons
- Simulated application form
- Application confirmation message
- Responsive layout for desktop and mobile

## How to run

Open `index.html` in a web browser.

For development, open the project in Visual Studio Code and use Live Server if it is installed.

## Important

This is an educational simulation. The companies, job offers, salaries and application process are fictional.

The website uses a CSS-based visual identity and does not depend on external image files.
