# My First Job

A simple educational web project for a Technical English final exam.

## Project idea

My First Job is a simulated platform designed to help students and young people find their first job opportunity.

## Technologies

- HTML5
- CSS3
- JavaScript

## Main features

- Responsive navigation menu
- Hero section
- About section
- Simulated job listings
- Job search
- Job type filter
- Application form
- Simulated application confirmation
- Responsive design for mobile and desktop

## How to run

Open `index.html` in a web browser.

For development in Visual Studio Code, you can also use the Live Server extension if you have it installed.

## Important

This is an educational simulation. The job offers, companies, salaries and application process are fictional.
